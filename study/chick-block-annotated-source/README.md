# 학습용 주석 달린 소스 코드

> **원본 코드는 수정하지 않았습니다.** 이 폴더만 공부용입니다.

## 다운로드 방법

1. **탐색기**에서 `chick-block-ledger\study\annotated` 폴더를 통째로 복사하거나
2. 폴더 우클릭 → **압축(zip)** → USB·클라우드로 옮기기
3. Cursor에서 파일 열기 → 전체 선택(Ctrl+A) → 다른 곳에 붙여넣기
