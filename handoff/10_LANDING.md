# 10 — 랜딩 페이지 (첫 실행 온보딩)

> Cursor 작업 지시서. 프로토타입 구현은 `components.jsx`의 `Landing` + `app.jsx`의 landing state 참조.

---

## 1. 정책 (★ 확정)

- **첫 실행 때만** 랜딩을 보여주고, "시작하기"를 누르면 다시는 안 보임.
- 토스 미니앱처럼 첫인상 + 컨셉 설명 역할. 이후엔 앱을 켜면 **바로 게임 화면**.
- "다시 보기"는 **내 정보 → 시작 화면 다시 보기** 버튼으로만 가능.

---

## 2. "다시 볼 수 없다" 문제 — 동작 원리 ⭐

랜딩을 한 번 보면 안 뜨는 건 **버그가 아니라 의도**이고, `localStorage` 플래그로 제어돼요.

### 핵심 코드 (app.jsx)
```js
// 첫 실행 여부를 localStorage 로 기억
const [showLanding, setShowLanding] = useState(() => {
  return localStorage.getItem("chick.seenLanding") !== "1";  // 키가 없으면 첫 실행
});

const startApp = () => {
  setLandingClosing(true);                          // 페이드 아웃 시작
  localStorage.setItem("chick.seenLanding", "1");   // ★ 봤다고 기록
  setTimeout(() => setShowLanding(false), 440);     // 440ms 후 언마운트
};

// 내 정보 → "시작 화면 다시 보기"
const replayLanding = () => {
  setLandingClosing(false);
  setScreen("home");
  setShowLanding(true);   // 플래그는 그대로 두고 다시 표시
};
```

### 다시 보는 방법 (3가지)
| 방법 | 용도 |
|------|------|
| **내 정보 → 시작 화면 다시 보기** 버튼 | 사용자/QA 정식 경로 |
| 브라우저 콘솔: `localStorage.removeItem("chick.seenLanding")` 후 새로고침 | 개발 중 "진짜 첫 실행"처럼 테스트 |
| 시크릿창/다른 브라우저로 열기 | localStorage 가 비어 있어 첫 실행 |

> ⚠️ `replayLanding` 은 플래그를 **지우지 않음** — 다시 보기로 띄운 뒤 "시작하기"를 또 눌러도 정상. "진짜 첫 실행" 테스트는 콘솔에서 키를 지워야 함.

---

## 3. 화면 구성

```
┌──────────────────────────────┐
│                              │
│      [ 기울어진 보드 히어로 ] │   ← 실제 Board 컴포넌트를 정지 렌더
│         (글로우 + 3D tilt)    │      (PNG 캡처 아님)
│                              │
│   🐤 병아리 블록 가계부        │
│   쓴 돈은 블록이 되어 쌓입니다 │
│   자잘한 지출이 합쳐져…       │
│                              │
│      ╭──────────────╮        │
│      │  시작하기 →   │        │   ← .landing-start
│      ╰──────────────╯        │
└──────────────────────────────┘
```

### 히어로 = 실제 보드 (★ 캡처 이미지 아님)
- `Landing` 이 `<Board>` 를 **정지 상태**(active=null, 애니메이션 off)로 렌더.
- `heroGrid = useMemo(() => makeInitGrid(), [])` — 시드 보드를 그대로 사용.
- `.landing-board-frame` 에 `perspective + rotateX(7deg) rotateZ(-1.5deg)` 로 3D 기울임 + 글로우.
- 장점: 별도 이미지 파일 불필요, 테마 따라 색 자동 반영, 항상 선명.

### 카피
- 브랜드: `병아리 블록 가계부` + save 병아리 로고
- 타이틀: "쓴 돈은 블록이 되어\n쌓입니다"
- 후크: "자잘한 지출이 공중에서 합쳐져 떨어지고,\n저축은 내 손으로 의식적으로 쌓는 가계부."
- → 카피는 자유 수정 가능. 핵심 메시지(지출 자동 / 저축 수동의 비대칭)만 유지.

---

## 4. 전환 연출 (★ 페이드)

- `.landing` 기본: `animation: landing-in 0.5s`(등장)
- "시작하기" → `.landing.closing` 클래스: **제자리에서 `opacity:0` 페이드 아웃** (`transition 0.45s ease-out`)
- 460ms 후 컴포넌트 언마운트 → 그 아래 게임 화면이 드러남

---

## 5. 테마 대응

- 랜딩 배경/글로우/시작 버튼은 **밤/낮 테마**에 맞춰 분기 (`[data-theme="light"]`).
- (숲 테마는 폐기됨 — 밤/낮 2종만.)

---

## 6. 검증 체크리스트

- [ ] localStorage 비운 상태(첫 실행)에서 진입 → 랜딩 표시
- [ ] "시작하기" → 페이드되며 게임 화면, 새로고침해도 랜딩 안 뜸
- [ ] 내 정보 → "시작 화면 다시 보기" → 랜딩 재등장
- [ ] 히어로 보드가 정지 상태로 깔끔히 보임 (블록 둥둥 애니메이션 off)
- [ ] 밤/낮 테마 각각 랜딩 색감 OK

---

## 7. 향후 확장 후보

- 랜딩을 **여러 장 스와이프 온보딩**으로 (지출 자동낙하 / 저축 수동 / 굳히기 3컷 설명)
- 첫 진입 시 닉네임·월수입 입력 받는 셋업 스텝
- 시작 버튼 위에 "이미 계정이 있어요" 보조 링크
- 랜딩 히어로 보드를 **느리게 자동 플레이**(블록 1~2개 떨어지는 데모 루프)
