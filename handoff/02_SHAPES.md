# 블록 모양 ↔ 지출 티어 매핑

> 어떤 테트로미노 모양이 어떤 금액 구간의 지출 블록으로 떨어지는지 정의.
> Pool이 임계 금액을 넘는 순간, 해당 티어의 후보 모양 중 **랜덤으로 1개** 선택해서 스폰한다.

---

## 매핑 표

| 모양 | 한국식 별명     | 셀 모양              | 티어   | 금액 구간     | 카테고리 힌트      | 후보 1지망 여부 |
| ---- | --------------- | -------------------- | ------ | ------------- | ------------------ | --------------- |
| **I**  | 일자            | ████ (한 줄 통째)    | red    | 50만+         | 월세·큰 결제·잔금   | ✅ 단독         |
| **L**  | ㄴ 거꾸로       | ▓<br>▓<br>▓▓         | orange | 10~50만       | 쇼핑·구독·전자제품 | ✅ (J와 랜덤)   |
| **J**  | ㄴ               | ░▓<br>░▓<br>▓▓        | orange | 10~50만       | 쇼핑·구독·전자제품 | ✅ (L과 랜덤)   |
| **T**  | ㅗ               | ▓▓▓<br>░▓░           | green  | 5~10만        | 외식·교통·생활     | ✅ (O와 랜덤)   |
| **O**  | 사각             | ▓▓<br>▓▓             | green  | 5~10만        | 외식·교통·생활     | ✅ (T와 랜덤)   |
| **S**  | 어긋난 위        | ░▓▓<br>▓▓░           | cyan   | 1~5만         | 편의점·소품·택시   | ✅ (Z와 랜덤)   |
| **Z**  | 어긋난 아래      | ▓▓░<br>░▓▓           | cyan   | 1~5만         | 편의점·소품·택시   | ✅ (S와 랜덤)   |

`blue` 티어(<1만)는 **블록 모양 없음** — 풀에만 누적되고 단독 블록으로는 떨어지지 않는다.

## 디자인 의도

### I = red (단독)
- 7개 셀 중 유일하게 가로/세로로 한 줄 전체를 차지할 수 있는 모양
- 큰 결제(월세 등)가 화면을 **물리적으로 압도**하는 시각적 임팩트를 위해 red 전용
- 한 줄을 통째로 먹지만 라인 클리어는 일어나지 않음 → "큰 지출의 무게가 그대로 남는다"

### L / J = orange
- 비대칭 ㄴ자 모양 — 쇼핑·구독 같은 "이번 달 큰 항목이지만 한 줄 정도는 아닌" 거래
- 두 모양 중 랜덤 선택해서 시각적 단조로움 방지
- 회전으로 4가지 방향 모두 가능 → 사용자 손맛 영역

### T / O = green
- 가장 "기본적"이고 안정적인 모양 — 가계부에서 가장 빈번한 외식·교통 구간
- 마음의 부담이 적은 평범한 지출. 그래서 모양도 평범.

### S / Z = cyan
- 어긋난 어색한 모양 — 자잘한 편의점 결제, 택시 처럼 "한 번 더 생각하면 안 썼을 수도 있는" 미세 지출의 어색함
- 빈도 높음 → 두 모양 랜덤 분산

### blue = pool only
- "지출이라 부르기도 민망한" 자잘함. 5천 원 커피, 천 원 단위 거래.
- 단독 블록 없음. 풀에 합산되어 더 큰 블록의 일부로 환생.

## 코드 표현 (예시)

```js
// game-data.jsx 추가
const SHAPE_BY_TIER = {
  cyan:   ["S", "Z"],
  green:  ["T", "O"],
  orange: ["L", "J"],
  red:    ["I"],
};

function randomShapeFor(tier) {
  const pool = SHAPE_BY_TIER[tier];
  return pool[Math.floor(Math.random() * pool.length)];
}
```

블록 스폰 시:
```js
spawnBlock(tier) {
  const shape = randomShapeFor(tier);
  const col = randomColumnFor(shape); // 라인 가득참 방지 보정 포함
  push to spawnQueue { shape, tier, col, rot: 0 };
}
```

## amount 표시 규칙

블록 자체가 "이 한 블록이 얼마짜리"인지 표시할 때:
- cyan 블록: 임계값 50,000원 — 표시는 "약 5만원" 또는 풀에서 실제 차감된 금액
- green: "약 10만원"
- orange: "약 50만원"
- red: 실제 단일 거래 금액 그대로 (예: 642,000원)

UX 상으로 사용자는 풀 누적이 어느 임계를 넘었는지만 인식하면 충분. 정확한 원 단위까지는 헤더 expense 합산에 반영.
